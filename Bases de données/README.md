# Base de données NextOri

## Base utilisée

MySQL (XAMPP)

Nom de la base : nextori_db_V2

## Contenu

- schema.sql : structure de la base de données
- seed.sql : données initiales

## Installation

1. Créer une base nommée nextori_db_V2.
2. Importer schema.sql.
3. Importer seed.sql.
